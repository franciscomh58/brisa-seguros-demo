# Contributor notes

Start with the [project README](README.md) and the [web app guide](web/README.md).
Application source and existing tests are under `web/src/`.

From `web/`, run `npm test -- --watch=false`, `npm run build`,
`node scripts/check-insurance.mjs`, and `node scripts/check-blog.mjs`.

Keep all people, insurers, products, and prices clearly fictional. Do not add
real personal data or imply that demo coverage is an offer. The app has no
backend or form submission.
